# Avito Max Parser 2.7.0

Обновлённое рабочее пространство для поиска и отслеживания выгодных объявлений.

## Изменения

- Новый дизайн панели, светлая/тёмная темы, адаптация 14 экранов под телефон, планшет и компьютер.
- Центр уведомлений: история доставки, ошибки и повторы, правила для каждого получателя Telegram, порог оценки «70+» и тихие часы.
- Общая сохраняемая в SQLite очередь запросов и паузы при 403/429/CAPTCHA с учётом Retry-After.
- Остановка повторяющейся выдачи и корректная пагинация; ошибки сохранения не повторяют запрос к источнику.
- Сохранение детальных характеристик при обновлении из выдачи; исправления цены, скоринга и устаревших уведомлений.
- Исправленные зависимости и установщики с воспроизводимым набором пакетов.

## Проверено

95 unit tests и три регрессионных сценария; Chromium на 14 экранах при ширине 360/768/1440; Windows/Linux Python 3.11/3.12/3.13; Docker. Все восемь проверок [CI для PR #25](https://github.com/domovoyproj/avito-parser/actions/runs/43474208930) прошли. Известных уязвимостей в проверенном наборе зависимостей не обнаружено.

## Установка и обновление

Требуется **Python 3.11.5 или новее**, рекомендуется Python 3.13. Архивы содержат исходники и установщики, это не автономные EXE.

Перед обновлением сделайте резервную копию БД. Версия схемы SQLite повышена до **11**. Для первого входа создайте администратора через `python setup_admin.py`; стандартного пароля нет.

Для Telegram укажите токен бота и получателей в настройках панели. Live-сбор Авито, CAPTCHA на реальном маршруте и доставка на реального получателя в этом обновлении не проверялись. Отсутствие блокировок не гарантируется, доставка уведомлений остаётся at-least-once.

Подробный отчёт: [docs/REVIEW_2_7.md](https://github.com/domovoyproj/avito-parser/blob/main/docs/REVIEW_2_7.md).
